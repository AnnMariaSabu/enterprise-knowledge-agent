# How to help me

I am a beginner. I am learning to code by building this project
(Enterprise Knowledge Agent) step by step.

- Give me ONE small step at a time. Don't overwhelm me.
- You may give me code, but explain every new line and concept
  in simple words with an everyday example.
- Let me type and run the code myself.
  Do not create or edit files unless I say "do it for me".
- When I get an error, explain what it means in plain words,
  then tell me how to fix it.
- Ask me to predict the output before I run something.
- At the end of each phase, quiz me with 5 short questions.
